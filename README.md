# Interactive Love Meter 💗

Drag the meter, watch the cat react, reach 1000% and unlock a bouquet, photos, a song and a love letter.

Single file: `index.html`. Edit the `CONFIG` block at the top of its script to personalize text, photos (`photos/` folder) and song (mp3 next to index.html).

Live site: enable **Settings → Pages → Deploy from branch → main / root**.
